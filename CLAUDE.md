# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Pull requests (required)
- Open every PR as a draft (`gh pr create --draft`) and keep it a draft until the user says it is ready. CodeRabbit reviews a PR once, when it is marked ready; ask for later rounds with an `@coderabbitai review` comment.
- One PR per repo per session: push follow-up changes to the PR the session already opened instead of opening a new PR for every change.
